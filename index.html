High-Yield Theory

🌐 บทที่ 4: Network Layer — Data Plane

หน้าที่หลักคือการ Forwarding แพ็กเก็ตจาก Input ไปยัง Output ภายในตัว Router/Switch เดียวกัน

1. IP Addressing & Subnetting

  • สูตร Host ที่ใช้งานได้: 2n - 2 (ลบ 2 เสมอ คือ Network ID ตัวแรก และ Broadcast IP ตัวสุดท้าย)
  • การแบ่งซับเน็ต (Borrowing bits): เช่น บล็อก /24 (256 IPs) ต้องการแบ่งเป็น 4 ซับเน็ตเท่าๆ กัน: ยืมบิต 2 บิต (22 = 4) prefix กลายเป็น /26 (ได้ซับเน็ตละ 64 IPs, ใช้ได้ 62 hosts/subnet)
  • การหา Network Address: นำ IP ของ Host ทำ Bitwise AND กับ Subnet Mask

2. NAT & DHCP & VLANs

  • NAT: แปลง Private IP หลายเครื่องในองค์กรให้ใช้ Public IP ตัวเดียวกันออกสู่อินเทอร์เน็ตผ่าน Translation Table (IP:Port)
  • DHCP (DORA): Discover → Offer → Request → ACK จ่าย IP, Subnet Mask, Default Gateway และ DNS โดยอัตโนมัติ
  • VLANs: แบ่งสวิตช์ 1 ตัวเป็นหลาย Broadcast Domains
    • Access Port: พอร์ตต่อ End-Device (ไม่มี Tag)
    • Trunk Port: ส่งต่อหลาย VLANs ข้ามสวิตช์ ต้องติด Tag IEEE 802.1Q (4 bytes)
    • Inter-VLAN Routing: ต้องมี Router หรือ L3 Switch เข้ามาช่วย
📌 Datagram vs Virtual Circuit:
• Datagram (IP ปัจจุบัน): ไร้การเชื่อมต่อ (Connectionless), Best-Effort, แพ็กเก็ตแต่ละตัวเดินทางอิสระ อาจสลับลำดับกันได้, ไม่มีรับประกัน Bandwidth
• Virtual Circuit (VC - เช่น ATM, X.25): ต้องทำ Call Setup เพื่อจองเส้นทางและกำหนดหมายเลข VC (VCI) ก่อนส่งข้อมูล แพ็กเก็ตจะเดินทางตามลำดับเดิมเสมอ

🗺️ บทที่ 5: Network Layer — Control Plane (Routing)

การหาเส้นทางข้ามเครือข่ายระหว่างเราเตอร์

RIP (Distance-Vector)

  • ใช้อัลกอริทึม Bellman-Ford
  • สูตรอัปเดต: Dx(y) = minv { c(x,v) + Dv(y) }
  • Metric: Hop count (จำนวนเราเตอร์ที่ผ่าน)
  • จำกัดสูงสุด: 15 hops (16 = Unreachable / เข้าไม่ถึง)
  • แลกเปลี่ยนตารางเฉพาะกับ เพื่อนบ้าน (Neighbors) เท่านั้น

OSPF (Link-State)

  • ใช้อัลกอริทึม Dijkstra's Algorithm
  • กระจายข้อมูลแบบ LSA (Link-State Advertisement) Flooding ให้ทุกเราเตอร์ใน Area ทราบสถานะลิงก์ของทั้งเครือข่าย
  • Metric: Cost (มักผกผันกับ Bandwidth: Cost = 108 / Bandwidth)
  • แต่ละเราเตอร์มี Global Topology Map เหมือนกัน แล้วคำนวณ Shortest Path Tree ด้วยตนเอง
⚠️ Count-to-Infinity & Poison Reverse (ออกข้อสอบชัวร์!):
• ปัญหาเกิดใน Distance-Vector เมื่อลิงก์ขาด แล้วเราเตอร์ A ยังคิดว่าไปถึงปลายทางผ่าน B ได้ ขณะที่ B ก็คิดว่าไปผ่าน A ได้ เกิด Routing Loop และค่า Hop นับบวกขึ้นไปเรื่อยๆ จนถึงอนันต์
• Split-Horizon with Poison Reverse: หากเราเตอร์ Z เรียนรู้เส้นทางไปยังปลายทาง X โดยผ่านเพื่อนบ้าน Y → Z จะรายงานกลับไปบอก Y ว่า DZ(X) = ∞ (หรือ 16) เพื่อป้องกันไม่ให้ Y ส่งข้อมูลย้อนกลับมาหาตน
• BGP (Border Gateway Protocol): ใช้หาเส้นทางระหว่าง Autonomous Systems (AS) ข้ามระดับโลก เป็น Path Vector Protocol
• ICMP: ใช้สำหรับแจ้ง Error และวินิจฉัยโครงข่าย (เช่น Ping, Traceroute, TTL Expired) ไม่ใช่โพรโทคอลสำหรับส่ง User Data

🔌 บทที่ 6: Link Layer & LANs

การตรวจจับความผิดพลาด & Media Access

  • Error Detection:
    • Checksum & CRC (Cyclic Redundancy Check): ทำหน้าที่เพียง Detect (ตรวจจับ) เท่านั้น ไม่สามารถแก้ไข (Correct) ได้!
    • หากต้องการแก้ไขบิตที่ผิดพลาด ต้องใช้เทคนิค FEC (Forward Error Correction) เช่น Hamming Code
  • CSMA/CD: ใช้บน Wired Ethernet แบบแชร์สาย (ฟังก่อนพูด ถ้าชนกันให้หยุด ส่ง Jam Signal แล้วสุ่มถอยแบบ Exponential Backoff)
    ⚠️ คำเตือน: ไร้สายไม่ใช้ CSMA/CD เพราะดักฟังสัญญาณชนขณะส่งไม่ได้ (ใช้ CSMA/CA แทน)

Switch Self-Learning & STP

  • Switch Self-Learning: สวิตช์เรียนรู้ MAC จาก Source MAC ของเฟรมที่เข้ามาเพื่อจับคู่ (MAC, Port, Timestamp)
    • หากส่งหา Destination MAC ที่ไม่มีในตาราง จะทำ Flooding ออกทุกพอร์ต ยกเว้น พอร์ตที่รับเข้ามา
  • STP (Spanning Tree Protocol - 802.1D): ป้องกัน Loop และ Broadcast Storm ในระบบสายเชื่อมโยงสำรอง (Redundant Links)
    • ค่า Cost ตามมาตรฐาน IEEE:
      - 10 Mbps = 100
      - 100 Mbps = 19
      - 1 Gbps = 4

📡 บทที่ 7: Wireless & Mobile

  • 802.11 Infrastructure Mode: มี Access Point (AP) เป็นศูนย์กลางคอยรับส่งข้อมูลระหว่าง Client ไร้สายกับระบบ LAN สาย
  • CSMA/CA (Collision Avoidance): โพรโทคอลหลีกเลี่ยงการชนกันบน Wi-Fi ด้วยการใช้ Inter-Frame Space (DIFS, SIFS) และ ACK
  • Hidden Terminal Problem: สถานี A และ C ส่งหา B แต่ A กับ C มองไม่เห็นกัน ทำให้สัญญาณชนกันที่ B → แก้ไขด้วยการใช้ RTS (Request to Send) / CTS (Clear to Send) handshake
  • 4G vs 5G: 5G ให้ความเร็วสูงขึ้นมากและมีความหน่วง (Latency) ต่ำระดับ 1 ms รองรับ Massive IoT และ Edge Computing ใช้เทคนิค OFDMA/NR ไม่ได้ใช้ CSMA/CD

🛡️ บทที่ 8: Security & Ethics

  • CIA Triad: Confidentiality (ความลับ), Integrity (ความถูกต้องสมบูรณ์), Availability (ความพร้อมใช้)
  • Encryption vs Integrity: การเข้ารหัสรับประกันแค่ Confidentiality เท่านั้น ไม่สามารถกันการดัดแปลงแก้ไขข้อมูลได้ (Integrity ต้องใช้ MAC / HMAC / Digital Signature)
  • ARP Spoofing: ส่ง Gratuitous ARP ปลอมเพื่อหลอกเครื่องเหยื่อว่า MAC ของตนคือ Gateway → โจมตีแบบ Man-in-the-Middle (MitM) ทำลายทั้ง Confidentiality และ Integrity
  • Mitigations: DAI (Dynamic ARP Inspection) ควบคู่กับ DHCP Snooping, Static ARP, Port Security, Private VLANs
  • จริยธรรมวิศวกรเครือข่าย: เมื่อได้รับมอบหมายให้ Packet Sniffing ต้องยึดหลัก Data Minimisation (ดักเฉพาะที่จำเป็น), เข้ารหัสไฟล์จัดเก็บ, กำหนดอายุการทำลาย, ห้ามแอบเปิดดูหรือเผยแพร่รหัสผ่าน/ข้อความส่วนตัวของผู้อื่นเด็ดขาด!

ข้อ 1: RIP Distance-Vector Algorithm (Bellman-Ford)

15 Points

โจทย์ตัวอย่างมาตรฐานข้อสอบ: กำหนดเครือข่ายมีเราเตอร์ 3 ตัวคือ x, y, z ที่เชื่อมต่อกันด้วย Link Cost ดังนี้:
c(x,y) = 2, c(x,z) = 7, c(y,z) = 1

สูตร Bellman-Ford: Dx(y) = minv ∈ neighbors { c(x,v) + Dv(y) }

ขั้นตอนการแสดงวิธีทำทีละรอบ (Round-by-Round):

Round 0 (Initial State)

แต่ละโหนดรู้เฉพาะระยะทางของตนเองไปยังเพื่อนบ้านที่ติดกัน:

RouterTo xTo yTo z
Dx027
Dy201
Dz710
Round 1 (หลังจากแลกเปลี่ยนเวกเตอร์)

โหนดคำนวณใหม่โดยใช้ข้อมูลจากเพื่อนบ้าน:

RouterTo xTo yTo z
Dx023*
Dy201
Dz3*10
*คำนวณ Dx(z) = min{c(x,y)+Dy(z), c(x,z)+Dz(z)}
= min{2+1, 7+0} = min{3, 7} = 3 (ผ่าน y)
Round 2 (Convergence!)

ส่งเวกเตอร์ซ้ำ ไม่มีค่าใดเปลี่ยนแปลงอีก:

RouterTo xTo yTo z
Dx023
Dy201
Dz310
✓ เครือข่ายเข้าสู่สภาวะ Converged สมบูรณ์ที่ Round 2!
// สรุปการตอบคำถามในกระดาษคำตอบข้อสอบ 1. ตาราง Round 1: D_x(z) ลดลงจาก 7 เหลือ 3 โดยมี Next-hop คือ y 2. ตาราง Round 2: ค่าคงที่ ไม่มีการส่งข่าวสารอัปเดตต่อ → สรุปว่า "Network has converged after Round 2" 3. Equal-cost routes: หากมีสองเส้นทางที่ผลรวม cost เท่ากัน ให้ระบุทั้งสองทาง (เช่น Next-hop สามารถโหลดบาลานซ์ได้) 4. Count-to-Infinity & Poison Reverse: - หากลิงก์ (y,z) ขาด: y จะต้องโฆษณาไปหา x ว่าระยะทางไป z คือ ∞ - Poison Reverse: ในยามปกติ z ส่งผ่าน y ไปหา x → z จะโฆษณาบอก y ว่า D_z(x) = ∞ ทันทีเพื่อกัน loop!

ข้อ 2: OSPF / Dijkstra Shortest Path Algorithm

15 Points

โจทย์ตัวอย่างมาตรฐาน: คำนวณหาเส้นทางที่สั้นที่สุดจาก Source Node u ไปยังทุกโหนด (v, x, y, w, z)
Link costs: (u,v)=2, (u,x)=1, (u,w)=5, (x,v)=2, (x,w)=3, (x,y)=1, (v,w)=3, (w,y)=1, (w,z)=5, (y,z)=2

สัญลักษณ์สำคัญในตาราง:
• N': เซตของโหนดที่ทราบเส้นทางที่สั้นที่สุดอย่างแน่นอนแล้ว
• D(v), p(v): ค่า Cost รวมปัจจุบันไปยังโหนด v และ predecessor node (โหนดก่อนหน้า)

ตารางแสดงวิธีทำข้อสอบแบบ Step-by-Step (ต้องเขียนตามนี้):

Step N' (Selected Nodes) D(v), p(v) D(x), p(x) D(y), p(y) D(w), p(w) D(z), p(z)
0 {u} 2, u 1, u ∞ 5, u ∞
1 {u, x} 2, u -- 2, x 4, x ∞
2 {u, x, y} 2, u -- -- 3, y 4, y
3 {u, x, y, v} -- -- -- 3, y 4, y
4 {u, x, y, v, w} -- -- -- -- 4, y
5 {u, x, y, v, w, z} -- -- -- -- --

ตารางสรุป Routing Table ของเราเตอร์ u (คะแนนก้อนสุดท้าย):

Destination Link Path Total Cost Next Hop
vu → v2v
xu → x1x
yu → x → y2x
wu → x → y → w3x
zu → x → y → z4x
💡 เทคนิคการทำข้อสอบ: ในแต่ละบรรทัด ให้มองหาโหนดนอก N' ที่มีค่า D() ต่ำที่สุด แล้วนำเข้า N' ในบรรทัดถัดไป จากนั้นอัปเดต (Relax) เพื่อนบ้านที่เชื่อมต่อกับโหนดที่เพิ่งเลือกเข้ามาใหม่

ข้อ 3: Virtual-Circuit Forwarding Table

12 Points

โจทย์: กำหนด Host H1 เชื่อมต่อกับ Switch 1 (Port 1), Switch 1 เชื่อมกับ Switch 2, Switch 2 เชื่อมกับ Switch 3, และ Switch 3 เชื่อมต่อไปยัง Host H2
ในขั้นตอน Call Setup ระบบได้กำหนด VCI ตามลำดับ ให้เขียนตาราง Forwarding Table ของ Switch แต่ละตัวทั้งทิศทางไป (Forward: H1 → H2) และทิศทางกลับ (Reverse: H2 → H1)

ข้อ 4: Spanning Tree Protocol (STP - IEEE 802.1D)

12 Points

โจทย์: สวิตช์ 3 ตัวเชื่อมกันเป็นวงรอบ (Loop) ดังนี้:
• Switch A (Bridge ID: 4096.AAAA)
• Switch B (Bridge ID: 8192.BBBB)
• Switch C (Bridge ID: 32768.CCCC)
ลิงก์ทั้งหมดเป็นความเร็ว 100 Mbps (Cost = 19)

ขั้นตอน 4 สเต็ปในการเขียนตอบข้อสอบ:

1. หา Root Bridge

เลือกตัวที่มี Bridge ID ต่ำสุด (Priority + MAC)
→ Switch A มี Priority 4096 ต่ำที่สุด → Switch A เป็น Root Bridge!
(ทุกพอร์ตบน Root Bridge จะกลายเป็น Designated Port (DP) เสมอ)

2. หา Root Port (RP) ของแต่ละสวิตช์

พอร์ตที่มี Root Path Cost ต่ำสุด วิ่งไปหา Root Bridge:
• Switch B → พอร์ตชี้ไปหา A มี cost = 19 (เป็น RP)
• Switch C → พอร์ตชี้ไปหา A มี cost = 19 (เป็น RP)

3. หา Designated Port (DP) ใน Segment (B - C)

บนสายเชื่อมโยงระหว่าง B และ C:
• สวิตช์ B มี Root Path Cost = 19
• สวิตช์ C มี Root Path Cost = 19
เมื่อ Cost เท่ากัน ให้ดู Bridge ID ต่ำกว่า: B (8192) ชนะ C (32768)
→ พอร์ตฝั่ง Switch B ชนะ เป็น Designated Port (DP)

4. หา Blocking Port (BP)

พอร์ตที่เหลือทั้งหมดซึ่งไม่ได้เป็น RP และไม่ได้เป็น DP:
→ พอร์ตบน Switch C ฝั่งที่ต่อกับ B จะกลายเป็น Blocking Port (Alternate Port)
ผลลัพธ์: ตัดวงจร Loop สำเร็จ เครือข่ายปลอดจาก Broadcast Storm!

ข้อ 5: Security & Ethics Case Analysis

6 Points
โจทย์สถานการณ์จำลอง: ผู้โจมตีส่ง Gratuitous ARP ตอบกลับเครื่องเหยื่อ (Victim PC) ว่า MAC ของตนคือ IP ของ Default Gateway ส่งผลให้ทราฟฟิกทั้งหมดถูกเปลี่ยนเส้นทางผ่านเครื่องผู้โจมตี

1. การวิเคราะห์ภัยคุกคามตามสามเหลี่ยม CIA (CIA Triad):

  • ประเภทการโจมตี: ARP Spoofing / ARP Cache Poisoning ซึ่งเป็นการโจมตีแบบ Man-in-the-Middle (MitM)
  • ผลกระทบต่อ Confidentiality (ความลับ): ผู้โจมตีสามารถดักส่องและอ่านข้อมูลสำคัญ เช่น รหัสผ่าน, เซสชันคุกกี้, ข้อความส่วนตัว ที่ยังไม่ได้เข้ารหัส
  • ผลกระทบต่อ Integrity (ความถูกต้อง): ผู้โจมตีสามารถดักจับและ แก้ไขเปลี่ยนแปลงเนื้อหา (Tamper/Modify) ก่อนส่งต่อไปยัง Gateway ปลายทางได้
  • ทำไม Encryption ถึงไม่พอ?: การเข้ารหัสปกป้องเพียง Confidentiality แต่ถ้าไม่มีการเซ็นลายเซ็นดิจิทัล (MAC/Integrity check) ผู้โจมตีอาจสับเปลี่ยนข้อมูลหรือโจมตีซ้ำ (Replay attack) ได้

2. มาตรการป้องกันทางเทคนิค (Technical Mitigations):

Dynamic ARP Inspection (DAI)

ทำงานร่วมกับ DHCP Snooping เพื่อตรวจสอบแพ็กเก็ต ARP ทุกตัวกับ Binding Database หาก MAC ไม่ตรงกับ IP ที่ DHCP จ่ายจริง สวิตช์จะ Drop ทันที

Static ARP & Network Segmentation

ล็อก Static ARP Table สำหรับ Default Gateway บนเครื่อง Server สำคัญ และแบ่งแยก VLAN (Private VLAN) ไม่ให้เครื่องลูกข่ายดักฟังกวนกันเอง

3. จริยธรรมวิศวกรเครือข่ายเมื่อต้องดักจับข้อมูล (Engineer's Ethical Duties):

✓ 1. Data Minimisation: ดักจับเฉพาะ Header หรือช่วงเวลา/โฮสต์ที่จำเป็นต่อการสืบสวนเท่านั้น ห้ามเก็บบันทึกทราฟฟิกทั้งหมดของทั้งบริษัทโดยไม่มีเหตุผล ✓ 2. Secure & Time-limited Storage: ไฟล์ .pcap หรือ log ที่ดักจับมาต้องเข้ารหัส (AES-256) และกำหนดระยะเวลาทำลายทิ้งทันทีเมื่อเสร็จภารกิจ ✓ 3. Strict Non-Disclosure: ห้ามนำ Credential, รหัสผ่าน, รูปภาพ หรือแชตส่วนตัวของพนักงานที่ติดมากับแพ็กเก็ตไปเปิดเผยหรือแสวงหาผลประโยชน์ส่วนตัวเด็ดขาด ✓ 4. Adhere to Privacy Policy: ปฏิบัติตามกฎหมายคุ้มครองข้อมูลส่วนบุคคล (PDPA/GDPR) และนโยบายขององค์กรอย่างเคร่งครัด

  • ❌ หลอก: Checksum สามารถแก้ไขข้อมูลที่ผิดพลาดได้
    ✅ จริง: Checksum และ CRC ใช้ Detect เท่านั้น ถ้าจะแก้ไขต้องใช้ FEC!
  • ❌ หลอก: Wi-Fi ใช้ CSMA/CD ในการเข้าถึงสื่อ
    ✅ จริง: Wi-Fi ใช้ CSMA/CA (Wired Ethernet ถึงใช้ CSMA/CD)

    ✅ จริง: Encryption รับประกันแค่ Confidentiality ส่วน Integrity ต้องใช้ Hash/MAC เพิ่มเติม
  • ❌ หลอก: Switch เรียนรู้ MAC Address จาก Destination MAC
    ✅ จริง: Switch เรียนรู้จาก Source MAC เสมอ!
  • ❌ หลอก: ICMP ใช้ส่ง User Payload ข้อมูลผู้ใช้
    ✅ จริง: ICMP มีไว้ Error Reporting และ Network Diagnostics (เช่น Ping, Traceroute)
